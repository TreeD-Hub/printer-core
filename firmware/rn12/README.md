# Firmware: RN12 (MKS Robin Nano V1.2)

Содержимое:
- `ROBIN_NANO.bin` — подготовленный бинарник Klipper для прошивки RN12 через microSD.

Почему именно такое имя:
- для Robin Nano загрузчик ожидает файл с именем `ROBIN_NANO.bin`.

Использование:
- порядок прошивки и подготовка бинарника описаны в `docs/rn_v12_to_klipper.md`.

Важно:
- держать в папке один актуальный артефакт;
- при замене бинарника проверять совместимость с текущей конфигурацией профиля `rn12_hbot_v1`.
