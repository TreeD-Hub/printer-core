# TreeD Mainsail Theme

Папка содержит активные файлы темы Mainsail, которые раскладывает лоадер.

Состав:
- `custom.css` — кастомные стили интерфейса;
- `sidebar-logo.svg` — логотип в боковой панели;
- `favicon-16x16.png`, `favicon-32x32.png` — иконки вкладки;
- `LICENSE` — лицензия исходных ассетов темы.

Деплой:
- шаг: `loader/steps/klipper-mainsail-theme.sh`
- источник: `mainsail/.theme`
- runtime-путь: `${PI_HOME}/printer_data/config/.theme`

Важно:
- не копировать сюда инструкции внешней ручной установки;
- любые изменения проверять в Mainsail после полного прогона loader.
