# Интеграционные проверки

Каталог содержит вспомогательные материалы для проверок в изолированной
системе. Они не входят в офлайн-набор [`tools/tests`](../tests/README.md).

- [`update-transition`](update-transition/README.md) — подготовка гостевой VM и
  проверка обновления с настоящими Moonraker, updater и systemd.
