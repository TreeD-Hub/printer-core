# Универсальный шаблон комментариев

## Шапка файла

```text
# ==========================================
# <ТИП/СЛОЙ>: <ИМЯ>
# ==========================================
# Назначение:
# - Кратко: роль файла.
# Контур:
# - required | best-effort | read-only (если применимо).
```

## Блоки логики

```text
# Блок 1: Подготовка контекста.
# Блок 2: Основной этап.
# Блок 3: Финализация.
```

Комментарии должны объяснять цель/контракт, а не синтаксис строки.
