# Универсальный шаблон README

Базовая структура секций задается в `.codex/repo-standards.yaml`.

Рекомендуемый каркас:

1. Что это за слой/каталог.
2. Состав файлов или подсистем.
3. Контракт/инварианты.
4. Runtime/Deploy (если применимо).
5. Запуск/проверка (если применимо).
6. Связанные документы.

Для каталогов-оркестраторов добавлять явный реестр сценариев (`required`/`optional`).
