# README Coverage

## Обзор

Проверять покрытие каталогов `README.md` по правилам профиля репозитория.
По умолчанию работать в check-only режиме; генерацию выполнять только с `--create`.

## Workflow

### Шаг 1. Запустить проверку покрытия

```bash
python skills/readme-coverage/scripts/readme_coverage.py --root <repo-root>
```

### Шаг 2. При необходимости сгенерировать шаблоны

```bash
python skills/readme-coverage/scripts/readme_coverage.py --root <repo-root> --create
```

### Шаг 3. Дозаполнить README фактическим содержимым

- Шаблонные файлы считать стартовой заготовкой.
- Описывать только то, что реально есть в коде каталога.

## Примеры триггеров

- `Проверь coverage README по всем подпапкам.`
- `Сгенерируй недостающие README по профилю проекта.`
- `Приведи структуру README к единому формату.`
