# legacy (rn12_corexy_v1)

Каталог хранит устаревшие конфиги профиля, оставленные только для rollback/сравнения.

## Состав

- `adxl345_rpi.cfg` — старый вариант ADXL345 через Raspberry Pi SPI.

## Правила использования

- Файлы в этом каталоге не подключаются в активной include-цепочке.
- Возвращать их в runtime только осознанно и отдельным изменением.
- Для совместимости в родительском каталоге есть shim `../adxl345_rpi.cfg`,
  который перенаправляет include в этот legacy-файл.
