# Runtime Scripts

Назначение этой папки: исходники runtime-скриптов, которые лоадер копирует на устройство.

Текущая модель:
- источник в репозитории: `runtime-scripts/*`
- деплой шагом: `loader/steps/treed-cam.sh`
- целевой путь на Pi: `/home/pi/treed/cam/bin`

Важно:
- это не операторские утилиты и не шаги лоадера;
- скрипты отсюда должны быть идемпотентными и безопасными для повторного запуска;
- имена и интерфейсы должны оставаться совместимыми с Moonraker shell_command.
