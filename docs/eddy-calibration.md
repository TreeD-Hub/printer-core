# Первичная калибровка Eddy

Инструкция для профиля `treed_v2_corexy_v1`. Eddy обязателен для штатного
Z-контура профиля. Без сохранённой Eddy-калибровки команды `PROBE`, mesh,
`START_PRINT` и рабочий поиск Z0 через Eddy не готовы к использованию.

## Критически важное условие Z

`PROBE_EDDY_CURRENT_CALIBRATE_AUTO` запускайте только при достоверной Z-позиции.
Если координата Z неизвестна, остановитесь: не запускайте AUTO как способ
получить Z и не полагайтесь на то, что макрос сам восстановит её. Для первого
запуска из неизвестной Z требуется отдельный проверенный для конкретного
принтера сервисный порядок.

## Порядок

1. Разместите Eddy примерно над центром стола, ориентировочно в 20 мм над
   поверхностью. Убедитесь, что Klipper загрузил активный профиль и что
   автоматическая калибровка не запущена во время печати или паузы.
2. Выполните drive-current calibration и сохраните результат:

   ```gcode
   TREED_EDDY_CALIBRATE_DRIVE_CURRENT
   ```

3. После рестарта восстановите достоверную Z-позицию по проверенному порядку
   нижней опоры этого принтера. В активном профиле `G28 X Y` сначала вызывает
   нижнюю опору при неизвестной Z, затем создаёт зазор и привязывает XY.
   Перед запуском высоты проверьте фактические homed XYZ:

   ```gcode
   G28 X Y
   TREED_EDDY_PRIMARY_HEIGHT_START
   ```

4. Следуйте интерактивным paper-test подсказкам Klipper. Примите точку и
   сохраните новую кривую:

   ```gcode
   TREED_EDDY_PRIMARY_ACCEPT_SAVE
   ```

   Запрет Z-home снимается после перезапуска только при совпадении загруженной
   кривой и XY с результатом `ACCEPT`. Прямой `ACCEPT` с `TREED_SAVE_CONFIG`
   не подтверждает сброшенный UI-контракт после смены тока/смещений.

5. Перед температурной серией очистите сопло от пластика. Для старта температура
   катушки Eddy, сопла и стола должна быть не выше 40 °C. Если хотя бы один
   компонент горячее, макрос выключит нагрев и включит обдув модели на полную
   мощность. Температуры проверяются каждые 5 секунд. Если любой ещё горячий
   компонент не остывает хотя бы на 0,2 °C за минуту или охлаждение длится
   10 минут, процедура завершится с ошибкой без запуска серии. Прежняя скорость
   обдува и тайм-аут простоя восстанавливаются при завершении или отмене;
   при ошибке или отмене нагрев остаётся выключенным. В UI охлаждение можно
   отменить отдельно. После охлаждения макрос проверит свободное состояние
   принтера, выполнит homing, поднимет
   сопло на Z=50 мм, прогреет его до 160 °C и переместит в центр стола на Z=1 мм
   для бумажной пробы. После первой принятой точки стол автоматически нагреется
   до 60 °C; это профильная безопасная температура для построения серии к
   `TARGET=56`. Предыдущие pending настройки должны быть сохранены или отменены.

   ```gcode
   TREED_EDDY_TEMPERATURE_START
   ```

6. Выполните бумажную пробу и принимайте каждую измеренную точку отдельно.
   Команда `TREED_EDDY_TEMPERATURE_ACCEPT` вызывает штатный `ACCEPT`; после
   каждого принятия проверяйте, продолжает ли датчик температурную серию.
   После достижения `TARGET` или минимум трех точек завершите измерения и
   сохраните серию:

   ```gcode
   TREED_EDDY_TEMPERATURE_COMPLETE_SAVE
   ```

   После успешного расчёта host-модуль проверяет свежие коэффициенты.
   Флаг завершения устанавливается после загрузки совпадающей кривой при
   следующем ready; отказ fit или сохранения не подтверждает серию.

   Для досрочной отмены используйте `TREED_EDDY_CALIBRATION_ABORT`: она
   вызывает штатный `ABORT`, удаляет незавершенные измерения и восстанавливает
   тайм-аут простоя, действовавший до старта. Совместимая команда
   `TREED_EDDY_TEMPERATURE_ACCEPT_SAVE` теперь выполняет полное завершение и
   сохранение серии; использовать её для отдельной точки нельзя.

   Проверить повторяемость штатных измерений можно на свободном и полностью
   homed-принтере командой `TREED_EDDY_PROBE_ACCURACY`. Она запускает обычную
   серию `PROBE_ACCURACY` и отклоняется во время печати, паузы или температурной
   серии.

`TARGET=56` — текущая профильная отправная точка. Если Eddy стабильно нагревается
выше этой температуры, выбирайте target по фактической температуре датчика.

## После калибровки

Для корректировки физического положения Eddy сохраните новые смещения:

```gcode
TREED_EDDY_SET_OFFSETS X=<мм> Y=<мм>
```

Команда перезапускает Klipper и сбрасывает зависимые этапы. До повторного
завершения первичной высотной калибровки штатный Z-home заблокирован.

Для небольшой поправки высоты на свободном homed-принтере используйте
`TREED_EDDY_Z_OFFSET_ADJUST DELTA=<мм>`: один шаг ограничен `-0.05..0.05` мм,
суммарный offset — `-1.0..1.0` мм. Чтобы применить поправку к калибровке Eddy и
сохранить её с перезапуском, выполните:

```gcode
TREED_EDDY_Z_OFFSET_SAVE
```

Сохранение доступно только после первичной калибровки высоты.
Постоянная поправка Eddy хранится в кривой высоты; отдельного сохранённого
числового `z_offset` у этого датчика нет. UI различает live-поправку,
несохранённые изменения кривой и подтверждённую после restart калибровку.

При замере карты через UI результат сохраняется автоматически: после успешного
сканирования и получения свежей карты UI вызывает `TREED_SAVE_CONFIG` и ждёт
перезапуска Klipper. Сохранение подтверждается только после сверки профиля
`default` с результатом замера. При ошибке замера или обновления статуса
автоматическая запись не выполняется.

Чтобы посмотреть карту перед записью через консоль, выполните
`TREED_EDDY_BED_MESH_CALIBRATE SAVE=0`. После просмотра результата отдельный
`TREED_SAVE_CONFIG` сохраняет профиль `default`. Без `SAVE=0` команда сохраняет
результат сразу, как в предыдущем контракте.

После рестарта проверьте homing и рабочий Z0:

```gcode
G28
TREED_Z_PARK_ZERO_EDDY
```

Для повторного применения конфигов после сохранения калибровки используйте
`TREED_DEPLOY_MODE=preserve` или `auto`. Режим `clean` может удалить Klipper
autosave-сегмент, в котором хранится калибровка.

`[force_move]` включён в профильный `probe_eddy_duo.cfg`.
