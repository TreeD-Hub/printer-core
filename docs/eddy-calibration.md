# Первичная калибровка Eddy

Инструкция для профиля `treed_v2_corexy_v1`. Eddy обязателен для штатного
Z-контура профиля. Без сохранённой Eddy-калибровки команды `PROBE`, mesh,
`START_PRINT` и рабочий поиск Z0 через Eddy не готовы к использованию.

## Критически важное условие Z

`PROBE_EDDY_CURRENT_CALIBRATE_AUTO` запускайте только при достоверной Z-позиции.
Если координата Z неизвестна, остановитесь: не запускайте AUTO как способ
получить Z и не полагайтесь на то, что макрос сам восстановит её. Для первого
запуска из неизвестной Z требуется отдельный проверенный для конкретного
принтера сервисный порядок.

## Порядок

1. Разместите Eddy примерно над центром стола, ориентировочно в 20 мм над
   поверхностью. Убедитесь, что Klipper загрузил активный профиль и что
   автоматическая калибровка не запущена во время печати или паузы.
2. Выполните drive-current calibration и сохраните результат:

   ```gcode
   LDC_CALIBRATE_DRIVE_CURRENT CHIP=btt_eddy
   TREED_SAVE_CONFIG
   ```

3. После рестарта независимо восстановите достоверную Z-позицию. Только после
   этого запускайте автоматическую калибровку:

   ```gcode
   PROBE_EDDY_CURRENT_CALIBRATE_AUTO CHIP=btt_eddy
   ```

4. Следуйте интерактивным paper-test подсказкам Klipper и выполните `ACCEPT`.
   Затем сохраните результат:

   ```gcode
   TREED_SAVE_CONFIG
   ```

5. После следующего рестарта снова восстановите достоверную Z-позицию до
   продолжения процедуры. Для компенсации температурного дрейфа выполните:

   ```gcode
   G28
   SET_IDLE_TIMEOUT TIMEOUT=36000
   TEMPERATURE_PROBE_CALIBRATE PROBE=btt_eddy TARGET=56 STEP=4
   ```

6. Выполните запрошенные paper-test шаги, `ACCEPT` и сохраните результат:

   ```gcode
   TREED_SAVE_CONFIG
   ```

`TARGET=56` — текущая профильная отправная точка. Если Eddy стабильно нагревается
выше этой температуры, выбирайте target по фактической температуре датчика.

## После калибровки

После рестарта проверьте homing и рабочий Z0:

```gcode
G28
TREED_Z_PARK_ZERO_EDDY
```

Для повторного применения конфигов после сохранения калибровки используйте
`TREED_DEPLOY_MODE=preserve` или `auto`. Режим `clean` может удалить Klipper
autosave-сегмент, в котором хранится калибровка.

`eddy_force_move_calibration.cfg` для этой процедуры не нужен: `[force_move]`
уже включён в профильном `probe_eddy_duo.cfg`.
