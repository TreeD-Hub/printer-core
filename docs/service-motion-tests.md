# Сервисные тесты движения

`TREED_XY_MOTION_TEST` — ручная проверка механики XY вне печати. Макрос
выполняет полный `G28`, поднимает голову на заданный `Z`, проходит тестовые
траектории, затем перемещает стол к `END_Z`. Не запускайте его во время печати
или паузы; оставайтесь у принтера и используйте значения, подходящие текущей
механике и состоянию устройства.

Начните с короткого прогона:

```gcode
TREED_XY_MOTION_TEST SPEED=150 ACCEL=3000 ITER=1 Z=20 END_Z=100
```

Текущие значения `VELOCITY`, `ACCEL` и `SQUARE_CORNER_VELOCITY` сохраняются и
восстанавливаются после теста. Для ручного возврата к ограничениям из `[printer]`:

```gcode
TREED_MOTION_LIMITS_DEFAULT
```

Параметры и дополнительные варианты смотрите в
[`macros-usage.md`](../klipper/profiles/treed_v2_corexy_v1/macros-usage.md#11-сервисные-команды).
