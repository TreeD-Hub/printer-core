# Plymouth Themes

Каталог `plymouth/theme/` содержит подпапки тем Plymouth, которые могут быть развернуты loader.

## Текущая активная тема

- `treed/`

## Контракт каталога тем

- одна тема = одна отдельная подпапка;
- внутри подпапки должны быть манифест `.plymouth`, script и графические ассеты темы;
- структура и имена файлов активной темы должны соответствовать проверкам в `loader/steps/plymouth-theme-install.sh`.

## Правила изменений

- не переименовывать файлы активной темы без синхронного обновления loader-шага;
- при добавлении новой темы документировать ее в `README` и в шаге деплоя (если она должна стать активной);
- учитывать, что часть ассетов может быть бинарной (png) и не подлежит правке в рамках текстового рефакторинга.
