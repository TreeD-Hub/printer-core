# Plymouth Theme: treed

Состав темы:
- `treed.plymouth` — манифест темы Plymouth.
- `treed.script` — скрипт отрисовки splash.
- `watermark.png` — фоновое изображение/брендинг.
- `prog.png` — индикатор/элемент прогресса.

Важно:
- шаг `loader/steps/plymouth-theme-install.sh` ожидает эти имена файлов;
- при переименовании нужно синхронно менять лоадер и проверку;
- тема устанавливается в `/usr/share/plymouth/themes/treed`.
